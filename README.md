# TaskManager - Sistema de Gerenciamento de Tarefas

> **Projeto Optativa 2 - TADS**  
> **Curso:** Tecnologia em Análise e Desenvolvimento de Sistemas (TADS)  
> **Instituição:** Instituto Federal do Norte de Minas Gerais (IFNMG)  

##  1. Sobre o Projeto
O **TaskManager** é uma plataforma multiplataforma desenvolvida para auxílio no planejamento, organização, priorização e acompanhamento de atividades pessoais e profissionais.

O projeto atende de forma integrada a todas as áreas avaliadas no curso[cite: 1, 5]:
- **Programação Orientada a Objetos (POO)**[cite: 1, 2]
- **Algoritmos e Estruturas de Dados**[cite: 1, 3]
- **Banco de Dados Relacional (3FN)**[cite: 1, 3]
- **Engenharia de Software e Modelagem UML**[cite: 1, 3]
- **Desenvolvimento Backend & API REST**[cite: 1, 3]
- **Desenvolvimento Web Responsivo**[cite: 1, 4]


##  2. Tecnologias Utilizadas
- **Backend:** Node.js / Express (Arquitetura RESTful em camadas)
- **Frontend Web:** HTML5, CSS3, JavaScript (Interface responsiva, Lista e Quadro Kanban)[cite: 2, 4]
- **Banco de Dados:** PostgreSQL / MySQL (Normalizado até a 3FN com Views e Triggers)
- **Versionamento:** Git e GitHub[cite: 4]
